A standalone WordPress plugin for Microsoft 365 integrations and plugin-owned WordPress features.

== Installation ==

1. Copy the MSPress directory to `wp-content/plugins/`.
2. Run `composer install` in the plugin directory when installing from source.
3. Activate MSPress from the WordPress Plugins screen.

== Usage ==

Use the example status shortcode: `[ms_press_status]`.
